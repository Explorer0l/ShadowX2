# 👥 Настройка нескольких администраторов ShadowX Bot

## 🔧 Как добавить второго администратора

### Способ 1: Автоматический (рекомендуется)

Используйте скрипт `add_admin.py`:

```bash
python add_admin.py <USER_ID> [USERNAME]
```

**Примеры:**
```bash
# Добавить админа с username
python add_admin.py 123456789 @second_admin

# Добавить админа без username
python add_admin.py 123456789
```

### Способ 2: Ручное редактирование

Отредактируйте файл `config.py`:

```python
# Multiple admins support
ADMIN_IDS = [
    6336309736,  # Primary admin (shahzod_bakiev)
    123456789,   # Second admin - ДОБАВЬТЕ СЮДА ID
]

# Admin usernames for display (optional)
ADMIN_USERNAMES = {
    6336309736: "@shahzod_bakiev",
    123456789: "@second_admin",  # ДОБАВЬТЕ СЮДА USERNAME
}
```

## 🔍 Как узнать USER_ID

1. **Через бота @userinfobot:**
   - Отправьте `/start` боту @userinfobot
   - Получите свой USER_ID

2. **Через логи бота:**
   - Запустите бота
   - Отправьте любое сообщение боту
   - В логах будет показан USER_ID

## ✅ Проверка работы

После добавления администратора:

1. **Перезапустите бота**
2. **Проверьте доступ к админ-панели:**
   - Отправьте `/start` новому админу
   - Должна появиться кнопка "👨‍💼 Админ панель"
3. **Проверьте функции:**
   - Просмотр очереди модерации
   - Управление модераторами
   - Очистка очереди

## 🛡️ Права администраторов

Все администраторы имеют **равные права**:

- ✅ Доступ к админ-панели
- ✅ Просмотр очереди модерации
- ✅ Одобрение/отклонение сообщений
- ✅ Управление модераторами
- ✅ Очистка очереди (`/clear_queue`)
- ✅ Сброс пользователей (`/reset_user`)
- ✅ Получение уведомлений о новых идеях
- ✅ Получение сообщений на модерацию

## 🔒 Безопасность

- ❌ Администраторы **не могут** удалить друг друга из модераторов
- ✅ Только администраторы могут добавлять/удалять модераторов
- ✅ Все действия логируются

## 🚀 Пример использования

```bash
# Добавляем второго админа
python add_admin.py 987654321 @admin_two

# Перезапускаем бота
python bot.py
```

## 📝 Примечания

- Изменения применяются только после перезапуска бота
- Старый `ADMIN_ID` остается для обратной совместимости
- Функция `is_admin(user_id)` проверяет всех админов из списка
- Уведомления отправляются всем администраторам
